# Screensaver

- SCR-01 A DreamService showing the featured items' backdrops full screen, each for 30 s with a slow zoom (Ken Burns,
  ≤ 6%), crossfading over 1.5 s; title and app in the bottom-left; the time and weather in the top-right.
- SCR-02 Without featured items (no key, no network) it shows a dark gradient with the clock.
- SCR-03 It loads only images already cached when possible and never keeps more than two full-screen bitmaps.
